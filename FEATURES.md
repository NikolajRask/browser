# Cool features to add to Lockin

Ideas that lean into the student / “lock in” identity. Already shipped (tabs, bookmarks, history, downloads, passwords, find, tab search, split view, study timer, calculator, todos, screentime) are left out.

## Focus & distraction

- **Lock-in mode** — one-click focus session: hide non-essential chrome, start the study timer, and block a custom list of distractor sites until the timer ends
- **Site blocker / allowlist** — block entertainment domains during focus hours, or allow only school / docs sites
- **Soft nudges** — if you open Reddit/YouTube mid-timer, show a “still locking in?” interstitial with Continue / Go back
- **Schedule lock-in** — auto-enter focus mode for class blocks (e.g. Mon–Fri 9–12)

## Study tools

- **Side notes panel** — markdown notes docked beside the current page; auto-link notes to the URL you’re on
- **Highlight & save** — select text on a page → save quote + source URL into a study notebook
- **Flashcards from highlights** — turn saved quotes / notes into spaced-repetition cards
- **Page summarizer** — AI or local summary of the current article into key bullets + vocabulary
- **Citation helper** — copy APA / MLA / Chicago citation from the current page in one click
- **PDF reader++** — annotate PDFs (highlight, sticky notes, export annotated copy)
- **Equation / LaTeX pad** — quick scribble board next to the calculator for homework

## Tabs & workflow

- **Tab groups by course** — color-coded groups (Math, History, CS) with collapse + restore
- **Session templates** — “Essay night” opens Docs + sources + notes in a saved layout
- **Reading list** — save-for-later queue separate from bookmarks, with unread count
- **Vertical tab strip** — optional side tabs for deep research sessions with lots of open pages
- **Picture-in-picture + lecture mode** — pop video into a floating window while notes stay full-screen
- **Workspace sync** — restore the exact tab set + split layout for each subject

## Productivity chrome

- **Command palette** (`⌘K`) — jump to tabs, bookmarks, todos, settings, and actions from one box
- **Quick capture** — global shortcut to dump a thought into Todos without leaving the page
- **Deadline widget** — upcoming assignments on the new-tab page (manual or calendar import)
- **Break reminders** — after N focus cycles, suggest a stretch / water break
- **Streaks & goals** — daily lock-in streak based on study-timer + screentime data

## Privacy & safety (student-friendly)

- **Exam / privacy mode** — one-shot clear of cookies + history for the last N hours
- **Per-profile spaces** — School vs Personal profiles with separate history, passwords, and blockers
- **Tracker / ad lite block** — lighter pages, fewer distractions on article sites
- **Download quarantine** — warn before opening unexpected `.exe` / macros from email links

## Polish & power-user

- **Custom new-tab** — greeting, today’s todos, streak, and pinned course links
- **Keyboard-first browsing** — vim-ish hints or full shortcut cheatsheet overlay
- **Reader mode** — strip clutter from long articles for focused reading
- **Mute / autoplay controls** — per-tab mute and “never autoplay media”
- **Extension bridge (limited)** — curated allowlist of student-useful extensions only

## Stretch / “wow” ideas

- **Study buddy rooms** — optional shared focus timer with friends (presence only, no chat spam)
- **Ambient focus audio** — built-in lo-fi / rain / cafe loops tied to the study timer
- **Screen-time coach** — weekly report: where time went vs. your course goals, with one suggested change
- **Offline course packs** — pin a set of pages/PDFs for flights or bad wifi
- **Handwriting / tablet mode** — stylus-friendly annotation overlay for lecture slides
